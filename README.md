# Book Library Management System

## Rhombix Technologies - Internship Task 1

This project is built with React and Vite.

### Task Requirements Covered

- Personal book library management
- Book search
- Book categorization
- Borrowing history

### Additional Features

- Dashboard statistics
- Add book
- Edit book
- Delete book
- Borrow book
- Return book
- Category filter
- ISBN search
- Responsive UI
- LocalStorage data persistence

### Run Project

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal, normally:

`http://localhost:5173/`
